Does AI Cheapen Talk? — File Architecture

Signaling game · React + Vite + Supabase · Generated 2026-05-08

  • ai-cheapens-talk/
    • src/
      • App.jsxGame state machine & all screen components
        • LoginScreen Username + shared password gate before game starts
        • RoleSelectScreen Two-step: choose role (Evaluator / Applicant) then field
        • AiOptionsScreen Applicant picks writing help: Full AI / Grammar only / None
        • SenderAnsweringScreen Applicant answers 2 MCQs — determines true expert status
        • SenderPitchingScreen Applicant writes pitch; optional AI improve / grammar buttons
        • RoundStart Evaluator sees the two questions before reading the pitch
        • EvaluateScreen Evaluator reads pitch + writing-help badge; clicks Hire / Pass
        • RevealScreen Shows outcome, correct answers, and payoffs for both players
        • GameOver Final scores + per-round history with payoff details
      • Dashboard.jsxResearch dashboard (/#dashboard)
        • DashboardGate Separate password (VITE_DASHBOARD_PASSWORD) before data is shown
        • Evaluator tab
          • Summary table Human accuracy vs AI baseline, by writing help (all fields)
          • Last 10 evaluators Name, field, rounds, correct count, accuracy, timestamp
          • FieldAccordion ×8 Per-field breakdown: N / Human accuracy / AI accuracy
        • Applicant tab
          • Summary table % hired (human) vs AI % hired (benchmark), by writing help
          • Last 10 applicants Name, field, writing help, rounds, % hired, timestamp
          • FieldAccordionApplicant ×8 Per-field breakdown: N / % hired / AI % hired
      • questions.js320 MCQs across 8 business fields 40 questions × 8 fields (Strategy, HR, Finance, Accounting, Operations, Marketing, Sales, AI & IS)
        Exports: QUESTIONS[], FIELDS[], getRandomQuestions(field, n, excludeIds)
      • openaiSender.jsOpenAI API wrappers generateSenderPitch · generateReceiverDecision · improvePitch · improveGrammar
        Model: gpt-4o-mini · temperature 0.7–0.85
      • supabase.jsSupabase client (null-safe) Reads VITE_SUPABASE_URL + VITE_SUPABASE_ANON_KEY; exports null if unconfigured
      • simulated-applicants.json480 pre-generated applicant pitches 8 fields × 3 writing-help × 2 expert status × 10 applicants
        Fields: id, field, writingHelp, isExpert, questions[], pitch
        Generated by generate-applicants.mjs
    • generate-applicants.mjsOne-time data generation script Calls GPT-4o-mini to write 480 pitches (base → improve → grammar)
      Output → src/simulated-applicants.json
    • benchmark-receivers.mjsAI evaluator baseline script Evaluates all 480 simulated applicants with same prompt as live game
      Output → benchmark-receivers.json · Overall accuracy: 46.7%
    • benchmark-receivers.json480 AI evaluation records (static baseline) Fields: applicantId, field, writingHelp, isExpert, aiDecision, correct, reasoning
      Bundled into Dashboard.jsx at build time for AI accuracy comparisons
    • schema.sqlSupabase table definitions receiver_decisions — one row per human evaluator round
      sender_rounds — one row per human applicant round
      RLS: anon insert + select policies on both tables
    • .env.localSecrets (not committed) VITE_OPENAI_API_KEY · VITE_SUPABASE_URL · VITE_SUPABASE_ANON_KEY
      VITE_GAME_PASSWORD · VITE_DASHBOARD_PASSWORD
    • package.json react · openai · @supabase/supabase-js · tailwindcss · vite

Data Flows

Human evaluator decision → Supabase: receiver_decisions — session_id, username, field, applicant_writing_help, correct, payoffs
Human applicant pitch → Supabase: sender_rounds — session_id, username, field, writing_help, pitch, ai_decision, payoffs
AI evaluator on AI applicants → benchmark-receivers.json — static file, bundled at build time, used as 2×2 baseline in dashboard
